# YGO Share - Gerenciador de Empréstimos

Um sistema simples para gerenciar empréstimos de cartas de Yu-Gi-Oh! entre amigos.

## Como publicar de graça no GitHub Pages

1. Crie uma conta no [GitHub](https://github.com/) se você ainda não tiver uma.
2. Crie um novo repositório chamado `ygo-manager` (ou outro nome que preferir).
3. Faça o upload do arquivo `index.html` que está dentro deste ZIP para o seu repositório.
4. No repositório, vá na aba **Settings** (Configurações).
5. No menu lateral esquerdo, clique em **Pages**.
6. Onde diz "Source", certifique-se de que "Deploy from a branch" está selecionado.
7. Em "Branch", selecione `main` (ou `master`) e clique em **Save**.
8. Aguarde de 1 a 2 minutos e o GitHub mostrará o link do seu site no topo dessa mesma página (ex: `https://seu-usuario.github.io/ygo-manager/`).

Pronto! É só mandar o link pro seu grupo e organizar os empréstimos.
